# HearMyMic

A free online microphone test that runs in your browser.

**Try it: [hearmymic.com](https://hearmymic.com)**

## What it does

- Live level meter, so you can see your mic pick up sound in real time
- Record 5 seconds and play it back to hear how you sound
- Hear yourself live, to check for echo and latency
- Webcam and mic test
- Guides for Zoom, Google Meet, Teams, Discord, Windows, macOS, iPhone, Android, PS5 and Xbox
- Fix guides for "mic not working" problems
- Available in English, Spanish, French, German, Portuguese, Japanese, Korean and Italian

## Privacy

Audio is processed in your browser. Nothing is recorded or uploaded to a server.

## Built with

[Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com), the Web Audio API and `getUserMedia`. Hosted on Cloudflare Pages.

## Run locally

```sh
npm install
npm run dev
```

Requires Node 24 (see `.nvmrc`).
